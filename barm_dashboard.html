n8n Workflow Automation — Auto-Upload CSVs to Supabase

🔗 How it Works

n8n watches a Google Drive folder (or email attachment). When you drop a new CSV, n8n reads it, maps the columns, and POSTs each row to Supabase via REST API. The forecast view auto-recalculates. Your dashboard shows live data within seconds.

📋 Step-by-Step Setup

  1. 1

    Install n8n (self-hosted or cloud)

    Install n8n via Docker: docker run -it --rm --name n8n -p 5678:5678 n8nio/n8n or sign up at n8n.cloud. Open localhost:5678.

  2. 2

    Create a New Workflow — Add Google Drive Trigger

    Node: Google Drive → On File Updated/Created. Set Folder to your "B-Arm Uploads" folder. Authenticate with your Google account. Set Poll Every: 15 minutes.

  3. 3

    Add: Read Binary File → Convert CSV to JSON

    Node: Spreadsheet File (Read from Binary). It auto-detects CSV and converts each row to JSON. Use Expression: {{ $binary.data }}

  4. 4

    Add: Switch Node — Route by Filename

    Add a Switch node. Route based on {{ $node["Google Drive"].json.name }}. Cases: AM_orders, FK_orders, Barm_online, etc.

  5. 5

    Add: HTTP Request → Supabase REST API (per table)

    Node: HTTP Request. Method: POST. URL as shown below. Add headers and body. Use Split In Batches node (batch=200) before this to handle large files.
